# Cyber Portfolio — Frontend

Frontend Angular del portfolio profesional de Alejandro Peña.

## Stack actual

Angular 22, TypeScript, SCSS, Angular Router, componentes standalone y SSR / prerenderizado.

## Ejecutar localmente

```bash
npm install
npm start
```

## Build y tests

```bash
npm run build
npm test -- --watch=false
```

La descripción del proyecto, su estado y roadmap están disponibles en el [README principal](../README.md).
