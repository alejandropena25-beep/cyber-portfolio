# Cyber Portfolio

Objetivo:
Crear un portfolio profesional que sirva como demostración de desarrollo,
ciberseguridad y DevSecOps.

Stack previsto:
- Angular 22 + TypeScript + SCSS
- NestJS
- PostgreSQL
- Docker / Docker Compose
- GitHub Actions
- Kubernetes
- Prometheus / Grafana

Fases:
1. Frontend Angular
2. Backend NestJS
3. PostgreSQL
4. Docker
5. CI/CD
6. Seguridad
7. Kubernetes
8. Observabilidad

Estructura inicial:
- /
- /projects
- /projects/:slug
- /about
- /contact

Categorías de proyectos:
- Cybersecurity
- Development
- DevOps

Reglas:
- TypeScript estricto
- Código limpio y mantenible
- No introducir dependencias innecesarias
- Explicar cambios importantes
- Ejecutar build/tests cuando proceda
- No hacer commits automáticamente
- No añadir tecnologías de fases futuras antes de tiempo
