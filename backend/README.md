# Cyber Portfolio — Backend

NestJS REST API that serves the confirmed public profile and project content for the Angular portfolio.

## Run locally

```bash
npm install
npm run start:dev
```

The API listens on `http://localhost:3000/api`.

## Validate

```bash
npm run build
npm test
```

PostgreSQL, authentication and administration are not part of Phase 3. See the [root README](../README.md) for the full architecture and roadmap.
